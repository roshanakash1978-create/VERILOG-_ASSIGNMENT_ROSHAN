The SR Flip-Flop, which is also known as the Set-Reset Flip-Flop is a part of memory that is controlled by two inputs: the Set input and the Reset input. The Set input is labeled as $S$. The Reset input is labeled as $R$. This thing is really useful because you can use it to make the output do what you want. You can make the output high. You can make it low or you can just tell it to stay the same.

Here is how the SR Flip-Flop works:

* When you Set the SR Flip-Flop, which means you make $S$ to 1 and $R$ equal to 0 it forces the output, which is labeled as $Q$ to be 1.
* When you Reset the SR Flip-Flop, which means you make $S$ to 0 and $R$ equal to 1 it forces the output $Q$ to be 0.
* When you do not do anything to the SR Flip-Flop, which means you make $S$ to 0 and $R$ equal to 0 it just stays the same so the next state of $Q$ is the same, as the current state of $Q$.
