D Flip-Flop

The D Flip-Flop is a common memory element in digital electronics.
It takes the value of the data input D at a moment.
Usually this moment is when a clock signal goes up.
Then it keeps that value at the output, Q until the clock signal goes up again.

Here's how it works:

* It acts like a storage that can hold 1 bit of information.
* Whatever is, at D goes to Q when the clock tick happens.

Here's the Truth Table:

* If D is 0 then the next value of Q is 0.
* If D is 1 then the next value of Q is 1.
